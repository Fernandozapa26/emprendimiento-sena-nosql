## Unidad de Emprendimiento del SENA

### 1. Elección del modelo NoSQL

Seleccioné MongoDB para el caso de la Unidad de
Emprendimiento porque permite almacenar documentos
con atributos diferentes según el sector de cada
iniciativa.

Por ejemplo, una iniciativa de tecnología puede
tener características diferentes de una iniciativa
de alimentos.

### 2. Consulta seleccionada

Q01: Consultar iniciativas activas por sector
y etapa didáctica.

Esta consulta permite identificar iniciativas
que necesitan acompañamiento y facilita
la organización de las actividades de asesoría.

### 3. Tipo de dato identificado

Date: permite almacenar fechas de manera adecuada
para realizar consultas y comparaciones temporales.

Durante la exploración comprobé que MongoDB
almacenaba las fechas de los documentos como Date.
